# **App Name**: PGK Legacy

## Core Features:

- Dynamic Content Display: Showcase a wide range of personalized gift products with detailed galleries and pricing, alongside comprehensive photography service portfolios.
- Order & Inquiry Management: Enable customers to submit requests for customized gifts and book photography sessions through interactive forms and direct links to WhatsApp and email, with data storage capabilities.
- Admin Content Management: Provide a secure web-based administration panel for John Solomon to effortlessly upload new products, update pricing, manage photography portfolios, and edit all website content without needing technical assistance.
- AI Gift Visualization Tool: An interactive AI-powered tool that allows users to upload their photos and instantly visualize them on different personalized gift products, with AI suggesting optimal design layouts and styling options to enhance their memories.
- Integrated Social & Map: Display the latest Instagram posts, embed an interactive Google Map for easy location finding, and provide readily accessible contact details including direct links for WhatsApp, phone, and email.

## Style Guidelines:

- The primary color scheme features a deep, elegant purplish-maroon (#3B0E39) for accents and key interactive elements, contrasted with a crisp off-white (#FAFCFB) for backgrounds and text in light mode.
- For dark mode, the background transitions to a rich, dark purplish-maroon (#3B0E39), with text and primary accents appearing in off-white (#FAFCFB) or a lighter shade for optimal readability and a sophisticated feel.
- A dynamic color scheme will support both light and dark modes, ensuring an accessible and visually appealing experience across user preferences, with all UI elements adapting seamlessly.
- Headlines will utilize 'Playfair' (modern serif) for an elegant, high-end feel, while body text will use 'PT Sans' (humanist sans-serif) ensuring clean readability and modern sophistication.
- Use a set of modern, clean, line-based icons for UI elements, ensuring clear visual communication. Standard brand icons should be used for social media links like WhatsApp and Instagram.
- Implement a mobile-first, responsive grid-based layout for all product and photography galleries, emphasizing large, high-quality images and clear hierarchy. A floating WhatsApp contact button will be persistently available.
- Incorporate subtle and smooth transitions for navigation elements, card hovers in galleries, and lazy-loading effects for images to enhance the modern and polished user experience without distractions.
